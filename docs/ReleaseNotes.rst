What’s new

Data update
^^^^^^^^^^^

-  Synchronized with `InterPro version 108.0 <http://www.ebi.ac.uk/interpro/release_notes/108.0/>`__.

-  An update to NCBIFAM (18.0), Pfam (38.1).
